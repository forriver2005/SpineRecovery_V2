# 鸟狗交付包：独立游戏场景

新增场景：`Assets/Scenes/BirdDog_RingSkinC_Delivery.unity`。

在 Unity 打开该场景运行，选择难度后开始。也可从原鸟狗游戏的动作选择／暂停菜单点击「鸟狗新评分场景」。新场景的暂停菜单支持继续、结束并查看成绩、返回原鸟狗游戏。切换到另一个游戏会结束当前训练。

此场景复制自 `BirdDog_RingSkinC_Recorded.unity`，保留星空圆环美术，并独立接入交付包的鸟狗规则。原场景中的旧训练流程在副本内停用；副本中的旧 RhythmModeController 被移除，避免全局启动器再开一个接收器。没有修改原游戏场景、共享评分脚本或共享模型／材质资产。

## 迁移内容

- `BirdDogHoldScorer`：A/B 识别、独立保持计时、扣分与每轮最高分结算。
- `BirdDogPose`：从实际模型骨骼测量对角肢体和支撑肢体。
- `BirdDogAnatomicalConstraint`：交付包的骨长、缩放、关节限幅和角速度限制；评分使用修正前的测量值。
- `RecordedBirdDogCoachMotion`：原录制 JSON 与双侧解剖镜像，教练播放独立于用户评分。
- 新游戏界面：四肢文字、对角音符、HIT／MISS、实时基础分／保持分／扣分、有效保持进度、上一轮成绩和本次汇总。
- VMC 接收：复用项目现有 EVMC4U、uOSC、AvatarMotionSource，UDP 39539，每个场景只有一个活动接收器。同步骨骼旋转，不同步外部根位置、根旋转、根缩放或骨长。

完整录制数据逐字节复制到 `Resources/BirdDogDelivery/bird_dog_recorded.json`。核心类型使用 `BirdDogDelivery` 命名空间，与原有同名类型隔离。交付包中与本项目不同的通用练习界面、流程控制器、SDK 和其他动作脚本未覆盖到项目中。原练习 HUD 的展示职责由本场景游戏界面接管。

为适配当前项目的 `AvatarMotionSource`，新评分器使用 `LastFrameReceivedAt` 检查输入新鲜度；原项目会缓存上一帧骨骼包数量，因此不能仅以该数量大于零判断仍在接收。其余评分、识别与约束阈值保持交付包定义。

## 规则与阈值

| 难度 | 基础分 | 保持分上限 | 加满保持分所需有效时间 |
| --- | ---: | ---: | ---: |
| 轻松（Easy） | 85 | 15 | 3 秒 |
| 标准（Medium） | 80 | 20 | 5 秒 |
| 挑战（Hard） | 75 | 25 | 7 秒 |

`实时分 = 基础分 + 保持分上限 × min(有效保持时间 / 目标时间, 1) − 姿态扣分`

- A：四点支撑，首次确认 0.20 秒。离开 A 需要肢体变化确认 0.08 秒。
- B：左臂＋右腿，或右臂＋左腿，确认 0.20 秒后锁定本侧。单肢、同侧手腿、四肢同时抬起不成立。
- 相对抬升识别阈值：轻松 0.38、标准 0.44、挑战 0.50；保持门槛比进入门槛低 0.13。
- 离开 B 持续 0.15 秒进入收回；四肢回到 A 持续 0.16 秒结算本轮最高分。可连续做同一侧。
- 未回 A 直接换侧不能累计另一侧时间；收回过程中同侧重新伸展，确认后可接续本轮已有时间。
- 过渡停滞 2 秒或单次过渡超过 12 秒会中止；中止与断线不虚构完成轮次。
- 输入年龄超过 0.35 秒停止有效采样；持续无效输入会清除当前轮次，恢复后需重新确认 A。暂停冻结识别确认、保持时间与教练示范。
- 稳定性：肢体高度／伸展量变化与角度归一化变化的最大速度不超过 1，才累计保持时间。
- 水平方向：臂、腿分别在 12° 内免扣，60° 达到单项上限。
- 竖直高度：臂、腿仰俯角绝对值分别在 10° 内免扣，45° 达到单项上限。
- 四项线性扣分，每项最多 1.25 分，各自保留两位小数，总计最多 5 分。手臂偏低 25° 对应扣 0.54 分。

更完整的支撑肢体、躯干和关节容差见评分器的 `BroadB` / `IsRest`；完整原始说明保存在 `Documentation/鸟狗训练场景导入与使用说明.pdf`。来源文件及校验值见 `Documentation/DeliveryProvenance.json`。

## 演示与呈现

教练采用录制的 0.7–3.2 秒伸展段、3.2–7.2 秒收回段，在伸展终点保持 7 秒，再镜像演示另一对角。教练保持长度不改变所选难度的用户计分目标。游戏音符跟随用户动作进度，不用教练的固定时间窗替代 A/B 评分。

左右相机分别呈现录制教练与真实输入模型。模型直接驱动骨骼时更新离屏蒙皮，并在约束、教练重定位后取景。用户预览朝向只通过相机调整，不改用户骨骼测量。运行时复制材质和颜色锚点网格，避免改变共享资源。四个肢体标签共用字号和缩放。
