# 死虫训练场景：导入与使用说明

本文件夹包含两项：

1. DeadBugRecordedPractice_Minimal.unitypackage：可导入Unity的场景与运行依赖包。
2. 本说明文档。

这是Unity资源包，需导入Unity工程使用；它不是Windows可执行程序。包内包含当前死虫动作、模型、教练演示、状态识别、人物约束、评分、录制回放及必要的共享脚本/插件，不包含原始IMU大文件、Library缓存和仿真报告。

## 1. 导入

建议使用Unity 2022.3.62f3c1，新建3D（Built-in Render Pipeline）工程。

在Window > Package Manager中确保安装：

| 包 | 版本 |
|---|---|
| TextMesh Pro | 3.0.9 |
| Unity UI（UGUI） | 1.0.0 |
| Input System | 1.7.0 |
| Timeline | 1.7.7 |

在Edit > Project Settings > Player > Other Settings中，将Active Input Handling设为Both；若Unity要求重启，完成重启。建议使用新工程导入，避免已有不同版本的VRM、UniGLTF、uOSC脚本产生重复定义；这些运行依赖已随包提供。

选择Assets > Import Package > Custom Package，导入本unitypackage并保留勾选。等待Unity编译完成后，执行：

**Tools > Dead Bug Package > Configure scenes**

该命令将死虫场景放在Build Settings第一项，并补齐回放、动作预览和包内入口场景。随后执行：

**Tools > Dead Bug Package > Open dead bug scene**

或直接打开：Assets/Scenes/DeadBugRecordedPractice.unity。

## 2. 场景入口与操作

| 场景 | 用途 |
|---|---|
| Assets/Scenes/DeadBugRecordedPractice.unity | 死虫连续训练，主要入口 |
| Assets/Scenes/CoachingChoose.unity | 动作预览；交付包目录只提供死虫录制 |
| Assets/Scenes/PlayBack.unity | 手动录制后的回放 |
| Assets/DeadBugDelivery/Scenes/CoachModeEntry.unity | 包内开始训练、动作预览与回放入口 |

打开训练场景后按Play，使用场景内开始/播放按钮进入训练。按语音和界面提示确认模型、完成准备位，再进行对角手腿伸展。顶部可选择简单、标准、挑战；暂停、继续、停止、录制及回放沿用场景现有按钮。当前分和上一轮最高分显示在左侧。

仅查看教练动作时，可通过包内入口的“动作预览”进入预览页。预览使用随包JSON，不需要访问原始录制目录。

需要导出Windows程序时，在File > Build Settings确认上述四个场景已启用、DeadBugRecordedPractice排在第一项，选择PC, Mac & Linux Standalone / Windows x86_64后Build；运行时保留生成的exe、Data文件夹及其他同目录文件。

## 3. 用户动作数据接入

评分需要有效的Humanoid骨骼输入，键盘鼠标不能替代IMU动作数据。场景使用EVMC4U/uOSC接收VMC骨骼姿态；请在数据发送端校准人体与设备，将输出IP和端口配置为场景接收器的监听地址/端口（接收器Inspector中的实际配置为准）。跨电脑使用时，目标IP应填写运行Unity的电脑IP。

用户模型的Animator必须为有效Humanoid，ExternalReceiver的Model应指向用户模型。评分输入通过AvatarMotionSource提供；替换输入适配器时，应为实际收到的新骨骼帧更新数据有效性与骨骼包计数，不能长期重复标记旧帧为新数据。当前包保留原场景接收链路，通常无需更改脚本。

未接入有效动作数据时，用户模型不运动、不能就绪或不能加分属于等待输入状态。请先检查发送端输出、接收器监听、Model引用及AvatarMotionSource是否收到骨骼帧。

## 4. 动作与状态

A是仰卧准备姿势：双臂向上竖直并伸直，大腿上举，小腿近水平，髋膝约90度。手脚平放地面不算A。

状态流程：**A → 对角伸展 → B保持 → 回位 → A**。

左手＋右腿或右手＋左腿均可进入B，另一侧保持准备位。两侧都允许，同侧也可重复；换侧前须完整回A。单臂、单腿、同侧手腿、四肢同时伸展都不能作为有效B。

首次A和B各确认约0.20秒，回A约0.16秒；轻微边界抖动采用滤波与滞回。过渡停滞2秒或累计12秒仍未完成，将取消未完成尝试并等待A。中途回收但未回A后，同侧再次伸展符合条件时可恢复同一轮；不会重复发放基础分。

教练使用录制7～10秒的右手左腿伸展、10～12.5秒回位，B端点额外保持，然后播放解剖镜像，循环演示两侧。原始动作JSON已随包包含，不依赖D盘的外部录制文件。

## 5. 评分

**当前分 = 基础分 + 保持加分上限 × min（有效保持秒数÷目标秒数，1）− 姿态扣分。**

| 难度 | 基础分 | 保持加分上限 | 有效保持目标 |
|---|---:|---:|---:|
| 简单 | 85 | 15 | 3秒 |
| 标准 | 80 | 20 | 5秒 |
| 挑战 | 75 | 25 | 7秒 |

进入B立即给基础分。活动手腿连续稳定约120毫秒后开始累计有效保持时间；快速摆动、暂停、回位和没有新动作包时不累计。短间隔保留已获得时间，持续缺失约350毫秒取消未完成轮次，恢复后先确认A。

全部难度共用四项扣分：手臂和腿部的水平方向偏角、竖直仰角，每项最多1.25分，总计最多5分。水平偏角≤12度免扣、≥60度扣满；竖直仰角绝对值≤10度免扣、≥45度扣满，中间线性计算。理想伸展方向为手臂向头侧、腿向脚侧，并与身体纵向一致、接近水平。界面显示具体中文原因与扣分值。

完整回A后保存本轮最高分及同一帧扣分原因。A的双臂伸直和腿部动作用于就绪与回位判定，不单独加分。

## 6. 人物约束与常见情况

用户模型具备关节范围投影、分部位转速限制、骨骼长度/缩放与无效旋转保护。评分读取修正前的输入，显示纠正不会自动替用户完成动作。严重异常帧不计分，恢复正常输入后可重新训练。

- 一直“等待A”：确认双臂竖直伸直、两腿抬起且屈髋屈膝，检查输入是否有效。
- 单肢动作后等待A：属于无效尝试，需要全部回位再开始。
- 进入B但有少量扣分：B识别门槛比满姿态宽松，按左侧具体原因调整方向和高度。
- 模型粉色或材质异常：使用Built-in管线，确认包内模型/材质/Shader已完整导入。
- 输入相关报错或按钮无响应：确认Input System已安装、Active Input Handling为Both并按提示重启。
- 无法进入回放或预览：重新运行Configure scenes，将支持场景加入Build Settings。
