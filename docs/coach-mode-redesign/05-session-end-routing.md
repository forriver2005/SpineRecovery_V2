# 模块 05：教练结束后的去向

> **旧版实现拆解，已废止。不要作为执行要求。** 完成页和路由唯一来源见 [12 号方案](12-keep-video-observation-and-coach-product-spec.md)，分模块执行提示词见 [13 号](13-codex-execution-prompts.md)。

## 目标

教练时间轴正常完成后，让患者明确选择下一步：已经会做，进入游戏模式；还需要看教练，再练一次。这个选择是用户操作，不是系统对康复掌握程度的判断。

## 需求

1. 播放链发布正常完成后显示一个清晰、无干扰的结束选择页，主要且仅有两个决策按钮：`我已学会，进入游戏模式`、`还需要学习，再来一次教练模式`。主页、动作库和回放等次要入口不能与这两个选择并列抢注意力。
2. 点击“进入游戏模式”沿用现有动作/游戏路由和参数；点击“再来一次”重新进入当前动作的教练流程，并重新执行课前朝向选择，不沿用上一次未确认的显示旋转。
3. 用户提前结束、安全停止、断连或技术中断时，仍遵循现有中断结果和安全流程；不要把中断误显示为正常完成后的两个选择。
4. 去向按钮不读取分数、不等待姿态达标、不改变训练次数，也不把“我已学会”写成客观临床结论。当前已有会话结果字段按原语义发送，不为本模块新增逐次评分历史或综合 `passed` 字段。
5. 返回/重开/重复进入时只修复真实的路由、重复回调或状态残留；不借机改 Android 历史页、游戏成绩或动作阈值。

## 文件边界与验收

先检查 `PracticeSessionController`、`MobileCoachControls`、`SpineFlowTrainingSession` 当前完成回调和手机路由，再改实际归属文件。Android 只有在当前入口确实由 Android 控制时才改对应导航，不新增结果展示体系。

验收：默认非处方 1 组 4 次完成后清楚看到仅有的两个主要选择；处方次数完成后同样出现选择；两个按钮分别进入正确路由；提前结束/安全停止不误显示；重练时朝向重新选择。完成选择不能无故等用户先站起来或等不相关的语音状态清空才呈现；如有安全需要应保留，但需避免卧位患者被长期挡住。播放、反馈和游戏模式原行为不被改变。
