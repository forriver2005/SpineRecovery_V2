# 旧版教练模式产品方案（已废止）

本文是早期草案，不能作为实现要求，也不要从本文补充提示词。Keep 完整视频观察、真实动作台本和最终患者流程以唯一权威文档 [12 号产品方案](12-keep-video-observation-and-coach-product-spec.md) 为准；Codex 总控和分模块提示词以 [13 号执行提示词](13-codex-execution-prompts.md) 为准。

## 1. 先说结论

教练模式要从“播放动画时顺便显示评分”改成“教练带患者学会一个动作”。播放是主节奏，语音是播放中的教学内容，动作观察持续运行，反馈跟随观察结果，任何动作是否做对都不能卡住播放。

一次动作训练的主路径是：

**动作介绍 → 教练完整示范 → 患者准备和完整倒数 → 逐次跟练 → 错误时告诉他怎么改 → 做到时对应部位变绿并同步震动 → 组间衔接 → 完成后由患者选择进入游戏或再学一次。**

这条路径必须让医院患者明显感到与现在不同。只新增事件、保留旧按钮、把颜色字段改成绿色，不能算完成。

## 2. Keep 调研得到的可借鉴模式

公开资料对 Keep 当前版本的定位是课程、教练陪伴和数据反馈；App Store 仍将“课程、跟练教练、训练反馈”作为核心体验。[Keep App Store](https://apps.apple.com/cn/app/keep-ai-%E8%BF%90%E5%8A%A8%E6%95%99%E7%BB%83/id952694580) 公开体验记录进一步描述了训练前的动作说明和教练示范、正式训练中的语音指导、准备时间和倒数、当前动作与进度、暂停/跳过/前后切换以及训练结束后的反馈。[Keep 训练体验报告](https://www.woshipm.com/evaluating/675421.html/comment-page-1) 公开的 Keep 训练页拆解也把训练视频、动作名称、组数进度、教程入口、暂停和下一动作放在同一条跟练流程里，并把语音和背景音乐作为可配置的伴随层。[Keep 训练页拆解](https://www.woshipm.com/rp/920011.html/comment-page-1)

可借鉴的不是某个按钮颜色，而是下面四个产品原则：

1. **先教后练。** 患者在真正跟做前就知道动作目的、起始姿势、要动哪些部位和最重要的注意点。
2. **教练带节奏。** 患者可以把注意力放在教练和自己的身体上，不必自己记组数、猜什么时候开始、猜什么时候保持。
3. **反馈是可执行的。** 错了要告诉患者改哪一处、怎么改；做对要马上确认是哪一处做对了。
4. **用户有控制权。** 可以暂停、恢复、重新播放或再来一次；播放不因识别抖动、短暂断连或一次没做到位而卡死。

Keep 的大众健身课程不能直接当成康复医嘱。康复动作的目的、呼吸、安全和纠错文案只使用项目已有审核内容或后续由康复专业人员审核的稿件。

## 3. 患者完整流程

### 3.1 开始前：让患者知道要学什么

进入某个康复动作后，页面先显示动作名称、简短目的和必要安全提醒。随后教练用自然速度完整示范一次，同时讲清楚：

- 起始姿势；
- 本次要动的身体部位，例如“抬左臂和右腿”；
- 动作方向和保持方式；
- 一个最重要的注意点；
- 必要时的呼吸或停止提示。

这段专属动作讲解不能被“教练介绍”“用户模型介绍”这类通用片段替代。若当前没有对应录音，交付物必须把待录内容列出来，不能用通用句冒充已经完成。

开始正式跟练前，保留现有准备语、完整倒数、数字之间的停顿、开始提示和视觉倒计时。Codex 不得因为播放轴紧而加快语音、剪掉尾音、删除倒数或压缩停顿。

### 3.2 正式跟练：默认一组四次

没有处方时，默认 **1 组 × 4 次**。有处方时，组数和次数由处方通路决定，不能被 1×4 覆盖。

每一次动作都由播放轴带着走：

1. 播放轴进入动作开始点，教练在动画真正开始时说清楚这一次要做什么，例如“抬左臂和右腿”；
2. 进入保持点时给出保持提示；
3. 进入回程点时给出回位、放松或下一步提示；
4. 播放轴推进到下一次，次数和整体进度同步更新。

动作方向口令不能等整段动画播完才出现。保持、回程、休息、下一动作等已有提示不能因为加入反馈而被省略。每条原有语音必须按原始速度完整播放；若现有动画时长装不下语音，应调整编排位置或增加明确的准备/保持时段，不能在运行时偷偷加速。

患者跟不上时可以暂停或重播当前动作。播放不会等待患者达标，也不会因为追踪短暂失效而把“未识别”当成“做错”。只有现有安全监督逻辑可以中断训练。

### 3.3 跟练中的动作反馈

产品语义只有三种：

- **需要纠正：** 不显示正确绿色，并播放一条简短、能执行的纠正口令，例如告诉患者放低哪条腿、保持哪一侧稳定。错误红显不是患者验收要求。
- **正确：** 只有当当前动作已有的正确条件成立时，对应部位绿色高亮。未达到正确条件时不亮绿；追踪无效、没有数据或处于阈值滞回区时也不亮绿。
- **未知：** 暂时没有可用追踪数据时不判对错，不用绿色误导患者；错误状态可留在内部诊断，不冒充患者反馈。

死虫、鸟狗优先用当前 Coaching 已有的几何正确条件；其他动作继续使用各自已经存在的正确判断。第一阶段不重新设计数值阈值，不使用游戏分数线替代动作部位条件，也不把“没有红色”当成做对。

一次动作涉及多个部位时，每个达到正确条件的部位分别变绿；当这次动作要求的部位全部达到正确条件后，对应的多个 tracker 在**同一个触觉事件**里同步震动一次。不能一个先震、另一个过一会儿再震，也不能保持正确时周期重复震。动作没有达到全部正确条件时不发这次成功震动。

做错的纠正语音要有节流，不能刷屏；但不能因为播放处于正式阶段就被一个“语音阶段忙碌”判断静默吞掉。安全、准备、动作方向和倒数优先于普通鼓励，纠错不能覆盖它们。

### 3.4 练习结束：患者自主选择下一步

正常完成后只突出两个决定：

- **我已学会，进入游戏模式**：沿用当前游戏入口和参数；
- **还需要学习，再来一次教练模式**：回到当前动作，并重新进行开始前朝向选择。

“我已学会”是患者的下一步选择，不是系统或医院对掌握程度的诊断。提前结束、断连、安全停止和技术中断不能伪装成正常完成。

## 4. 四条链路如何协作

### 播放/教学链：主节奏

负责动作介绍、完整示范、准备、倒数、动作阶段、保持、回程、休息、次数和暂停恢复。它拥有唯一的训练时钟。语音 cue 必须挂在实际动作节点上，保持完整原速。

### 动作观察链：持续观察

持续消费传感器和已有动作判断。它不建立“某个固定时间窗才评分”的机制，不显示分数，不推进次数，不等待用户做对。

### 反馈链：只表现结果

根据观察链的正确/需要纠正/未知状态驱动红色、绿色、纠正语音和同步触觉。绿色只能由正确条件驱动；反馈链不能反过来控制播放链。

### 会话结果链：收尾和路由

负责默认/处方训练量、当前次数、正常完成、中断和完成后的两个去向。它不重新计算动作分数，不增加未经要求的历史评分协议，不改变游戏模式。

这四条链通过明确事件连接，互相不能用隐藏的全局状态阻塞。播放主节奏不等观察，观察不改播放，反馈不重复计次，结果链不把“我已学会”写成医疗结论。

## 5. 朝向模式

开始前给患者一个清楚的二选一，并显示当前选中状态：

- **模式 A（默认）：** 教练在训练中持续跟随用户模型的方向旋转，保持面对用户的教学关系；旋转要平滑，不能因为传感器抖动快速摆动。
- **模式 B：** 教练保持确定的场景视角，用户显示模型跟随并对齐教练朝向。

选择只在教练开始前生效，训练中不切换。重练必须重新显示选择，不能把上一次的旋转残留到下一次。朝向只影响显示和教练关系，不影响阈值、播放、游戏和传感器计算。

## 6. 本次明确不做的事

- 不新增背景音乐。医院交付阶段语音指导优先，游戏 BGM 不复用到教练模式；以后有合适且授权的音乐再单独评估。
- 不改游戏模式的玩法、分数、阈值、难度和结果。
- 不重新发明死虫、鸟狗或其他动作的临床阈值。
- 不删减已有语音、倒数、停顿、准备和结束提示。
- 不新增庞大的评分历史、医疗掌握结论或 Android 结果页体系。

## 7. 可交付的模块顺序

1. **内容清单与播放教学链**：先盘点每个动作的讲解、示范、准备、动作开始、保持、回程、纠错、正确反馈和转场内容，建立真实播放节点。
2. **语音接线与节奏保护**：保证所有已有语音原速完整播放，动作口令落在动作节点，错误纠正不被播放阶段吞掉。
3. **连续观察与正确反馈**：修正绿色状态来源，接通正确部位绿显和多 tracker 同步单次震动，保留错误纠正。
4. **朝向模式**：实现默认 A、可选 B、开始前选择和视觉选中状态。
5. **完成分流**：收敛为进入游戏/再练教练两个主要决定，清理重练状态。
6. **集成验收**：至少用死虫、鸟狗和一个臀桥/腰背动作完整演示一遍。

模块可以由不同 Codex 对话负责，但涉及同一工作树时必须按上述依赖顺序合并，不能让多个对话同时覆盖同一批脚本。

## 8. “完成”必须用患者路径证明

实现者必须能够在可运行场景中证明：

1. 开始前听到当前动作专属讲解并看到完整示范；
2. 每次动作的方向口令出现在动作开始，而不是动作结束后的 hold；
3. 旧准备语、完整倒数和停顿仍按原速存在；
4. 做错时看到需要纠正的部位并听到可执行纠正；
5. 未达到正确条件时不绿，达到时对应部位绿显；
6. 死虫或鸟狗的多个目标同时正确后对应 tracker 同步震一下，之后不重复震；
7. 没有追踪或短暂断连不会卡住播放；
8. 正常完成后只有“进入游戏”和“再练一次教练”两个主要选择。

编译通过、事件存在、颜色枚举改成绿色、按钮改了文字、保留了音频引用，都不能代替以上用户路径验收。无法试听或无法连接真实 tracker 时必须明确写出未验证项，不得报告为已完成。
