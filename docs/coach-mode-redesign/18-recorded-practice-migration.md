用户明确新死虫为四肢举起、当前对侧两肢放下到位才亮绿。新场景使用 `RecordedPracticePoseGuidance`：缓存各侧录制末端的上下肢段方向，去掉整体偏航但保留重力方向；只有当前目标的两个肢段都进入到位角度窗口，才产生正向结果。沿用项目已有14°清除、24°激活窗口数值；滞回区不亮。旧死虫/鸟狗的35°/45°等 Coaching 条件没有修改。

仍经过真实VMC新鲜度、对应tracker有效状态、目标部位和硬约束检查；非目标、准备、回位、未知状态不亮。参考姿势匹配证明“接近这份示范”，不能等同康复专业认可了该示范的全部动作幅度。
