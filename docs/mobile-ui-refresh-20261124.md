## 数据与交互

- 保留既有问卷、首次评估、疼痛阈值、训练处方与保存接口。医生下发的题目、选项值、范围和必填约束是问卷内容来源，不把设计稿的示例答案写入用户记录。
- 问卷答案按顺序保存；失败答案保留并可重试。切换账号时清空本账号的问卷视图和请求状态，迟到回调不会更新新账号界面。
- 只有服务端返回完成状态时显示已完成页；提交中禁止编辑答案。
- 历史记录按时间排序。得分缺失或旧 JSON 损坏时显示缺失状态；优先使用记录内的训练时长。既有导入回放入口仍可用。
- 390 设计单位适配可用屏幕宽度，页头/底部按钮固定，长内容滚动。沿用应用的安全区处理。
