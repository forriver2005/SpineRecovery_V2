脊柱康复·六项游戏测试版（安卓手机 / 平板，横屏）

使用方法
1. 将桌面 SpineRecovery_六项游戏测试_20261030.apk 复制到安卓设备并安装（Android 8.0 或更新版本）。
2. 开始界面右上角“动作选择”，或训练中的暂停界面，都可以切换：鸟狗、死虫、臀桥动态、臀桥保持30秒、侧桥动态、侧桥保持30秒。
3. 切换动作会结束当前训练，重新进入所选动作的开始界面。暂停时音乐、教练、游戏节奏和训练计时一起暂停。
4. 本版本需要真实动作数据并完成校准，只有教练动画不会产生训练成绩。侧桥按现有录制采用左侧支撑。

SlimeVR 连接手机 / 平板
1. 双击桌面原来的 SlimeVR 快捷方式。它已指向“SlimeVR_修复版”，请保留这个文件夹。
2. 电脑、安卓设备和追踪器连接同一局域网；在 SlimeVR 中完成追踪器身体部位分配、佩戴方向与重置校准。
3. 安卓应用的“动作选择”页面显示本机 IP。进入 SlimeVR 设置中的 OSC / VMC，启用 VMC 输出，将目标地址改为安卓设备的 IP，输出端口填 39539。输入端口为 39540。
4. 当前软件验证使用 127.0.0.1:39539（同一电脑上的 Unity）；连接手机时必须将目标地址改成手机的 IP。
5. 返回游戏，按开始界面的提示校准后训练。若更换 Wi-Fi 或设备 IP，请更新 SlimeVR 的目标地址。

关于模型朝向
六个场景的用户模型已检查：T Pose 初始骨骼旋转为零、左右骨骼对应正确、脚尖向前、蒙皮绑定与初始姿态一致。无需再次手动 Freeze T-Pose。
模型的 Freeze T-Pose 与实际追踪器的佩戴校准是两回事：更换佩戴位置后仍需在 SlimeVR 中完成重置 / 校准。

已验证与待验证
已完成六场景选择、开始、暂停、恢复、切换清理，以及实际 SlimeVR 服务 -> VMC UDP -> Unity 用户模型的软件链路验证。
另外逐个验证20个关节及192个录制动作采样姿态，未发现软件骨骼错配、重复旋转或复位残留；蒙皮与 Unity 动作重定向结果一致。
此次追踪器未连接、安卓设备未连接电脑，实际佩戴方向、IMU漂移、局域网丢包、设备运行性能和震动反馈仍需你的实机测试。
测试创建的虚拟追踪器已清理，不会混入你的真实设备。

原 Program Files 安装未覆盖，原快捷方式备份位于“SlimeVR_修复版/原SlimeVR快捷方式.lnk”。
界面自动化在你按 Esc 后已停止；请自行双击快捷方式启动。
